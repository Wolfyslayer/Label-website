# Site content (GitHub-editable)

Edit files here and push to `main` to update **https://wolfyslayer.online** (GitHub Pages rebuilds automatically).

| Folder | Purpose |
|--------|---------|
| `site.json` | Label story, featured release, press assets |
| `artists/` | Frostmark & Wolfyslayer profiles |
| `releases/` | Singles, EPs, albums |
| `tracks/` | Tracklist entries linked to releases |
| `news/` | News articles (Markdown + YAML frontmatter) |

Full guide: **[docs/CONTENT_MANAGEMENT.md](../docs/CONTENT_MANAGEMENT.md)**

Before pushing, run locally: `npm run validate:content`
