# WOLFYSLAYER RECORDS — Website Assets

## Contents
- `artists/`: The TWO user-supplied original profile images and optimized 512/1024px WebP copies. These are the authoritative artist portraits.
- `banners/`: 2560x1024 and 1280x512 WebP banners composed from the real portraits. No baked-in text, so Swedish/English headings can be overlaid in the website.
- `logos/`: Original custom editable SVG wordmarks in three colors, PNG exports and an independent icon mark. These are newly designed simple geometric marks, not replicas of existing artist logos.
- `favicons/`: SVG and PNG icon sizes.
- `backgrounds/`: Darkened original-image backgrounds for overlay text.
- `social/`: 1080x1080 social graphics based on the supplied portraits.
- `docs/design-concept-board.png`: AI-generated visual reference sheet only; do not treat its small elements as production-ready artwork.
- `docs/colors.json`: Suggested site palette.

## Cursor setup
Copy assets to `public/assets/` in your Next.js project. Example: `/assets/banners/label-hero-2560x1024.webp`. Use CSS `object-fit: cover`, responsive `object-position`, and put translated Swedish/English headings as actual HTML text over banners. The logo SVG uses system Georgia; exact letterform appearance may vary by device.

## Important
This pack includes no invented album covers, fake music releases, fake social logos or fabricated artist photos. Use actual cover artwork and official streaming icons/links separately. The banner images are composites of the supplied portraits, not separate AI-created scenes. Check commercial suitability and originality of generated brand elements before registering a trademark.
